# سيرفر الحضور المحلي — أكاديمية نبراس

جهاز صغير داخل الأكاديمية يخلّي تسجيل الحضور والانصراف شغال حتى لو النت قطع. الموظفين بيمسحوا الـ QR وهم على Wi-Fi الأكاديمية، والجهاز بيحفظ التسجيلات ويبعتها للنظام أول ما النت يرجع. لو اتبعتت مرتين ما بتتكررش.

## المطلوب

- كمبيوتر أو Mini PC شغال طول اليوم وموصل بشبكة الأكاديمية (Windows أو Linux).
- شاشة للاستقبال تعرض الـ QR (ممكن تكون نفس الجهاز أو تابلت يفتح صفحة الشاشة).
- Node.js 18 أو أحدث.
- عنوان IP ثابت للجهاز على الشبكة (من إعدادات الراوتر) عشان الـ QR يفضل شغال.

## الإعداد (مرة واحدة)

1. على سيرفر Hostinger أضف في ملف `.env` متغير `ATTENDANCE_SYNC_SECRET` بقيمة عشوائية طويلة:
   ```
   node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
   ```
2. على الجهاز المحلي: انسخ فولدر `local-server` ثم:
   ```
   npm install
   copy config.example.json config.json
   ```
3. عدّل `config.json`:
   - `cloudUrl`: رابط الموقع.
   - `syncSecret`: نفس قيمة `ATTENDANCE_SYNC_SECRET`.
   - `kioskKey`: قيمة عشوائية طويلة (بتفتح شاشة الـ QR).
   - `localUrl`: اتركه فاضي ليتحدد تلقائياً، أو اكتب العنوان الثابت مثل `http://192.168.1.50:4000`.
4. شغّل: `npm start` (أو `start-local-attendance.bat` على Windows).
5. افتح على شاشة الاستقبال: `http://<عنوان-الجهاز>:4000/kiosk?key=<kioskKey>`

## ربط هاتف كل موظف (مرة واحدة وهو متصل بالإنترنت)

1. الموظف يتصل بـ Wi-Fi الأكاديمية ويمسح الـ QR لأول مرة.
2. يضغط "ربط الهاتف" ← يدخل على البوابة بحسابه ← يرجع تلقائياً وقد تم الربط.
3. بعدها المسح بيشتغل حتى لو النت مقطوع.

## ملاحظات

- التسجيلات محفوظة في `data/scans.jsonl` وحالة المزامنة في `data/state.json`. خد نسخة منهم دورياً.
- لو حساب موظف اتعطل على النظام، السيرفر المحلي بيعرف ده في أول مزامنة ويرفض تسجيلاته بعدها.
- صفحة الحالة: `http://<عنوان-الجهاز>:4000/status?key=<kioskKey>` (عدد التسجيلات وآخر مزامنة).
- لو عندكم نت مستقر، ممكن تستغنوا عن الجهاز المحلي وتستخدموا شاشة QR من النظام نفسه (الحضور ← الشاشات).
