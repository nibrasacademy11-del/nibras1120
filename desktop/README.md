# تطبيق الإدارة على الكمبيوتر (Nibras Admin)

ده نفس بوابة الإدارة الموجودة على الموقع، بس في برنامج مستقل على الكمبيوتر. مفيش قاعدة بيانات جديدة ولا نظام منفصل: نفس السيرفر ونفس البيانات ونفس الصلاحيات.

## اللي بيضيفه التطبيق

- نافذة مستقلة بتفتكر حجمها ومكانها، ونسخة واحدة بس شغالة في نفس الوقت.
- **حفظ PDF حقيقي بمقاس A4** من القائمة (ملف ← حفظ PDF أو Ctrl+Shift+S). الشهادات والتقارير العرضية بتتحفظ بالعرض لوحدها.
- طباعة مباشرة (Ctrl+P).
- لو النت قطع بتظهر صفحة "إعادة المحاولة" بدل شاشة فاضية، وبيحاول تاني لوحده لما النت يرجع.
- أي رابط خارجي بيفتح في المتصفح العادي، والتطبيق مش بيفتح غير موقع الأكاديمية.
- مخصص للموظفين والإدارة؛ لو عميل حاول يدخل منه بيتوجه للموقع.

## التشغيل والتجهيز

محتاج Node.js 18 أو أحدث على جهاز التجهيز.

```
cd desktop
npm install
npm start          # يفتح التطبيق على الموقع الحقيقي
npm run dev        # يفتح على السيرفر المحلي http://localhost:3000
npm run dist       # يعمل ملف تثبيت Windows في desktop/dist
```

- رابط الموقع: الافتراضي `https://www.nibras-ac.com`. لتغييره اعمل `desktop/config.json` فيه `{ "siteUrl": "https://..." }`.
- الأيقونة: حط صورة الشعار باسم `desktop/icon.png` (مربعة، 512×512) قبل `npm run dist`.

## ملاحظات

- ملف التثبيت غير موقّع رقمياً؛ Windows ممكن يظهر تحذير "Unknown publisher" أول مرة. للتخلص منه يلزم شهادة توقيع كود باسم الأكاديمية.
- التحديث التلقائي غير مفعّل: التطبيق بيعرض دايماً آخر نسخة من البوابة لأنها من السيرفر، ومحتاج تحديث للبرنامج نفسه بس لو اتغير ملف `main.js`.
